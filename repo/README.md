## 各ファイルの構成

各回のMarkdownファイルは、元のメモの内容を保ったまま以下の形式に統一しています。

- `# タイトル` … その回のタイトル
- `## N. 見出し` … 元メモの話題ごとの区切り
- `### 小見出し` … 話題内のサブトピック
- 箇条書き（`-`）… 元の「●」「○」を変換
- `> **Q:** / **A:**` … 授業中の質疑応答
- 表 … 各回末尾の「今回のショートカット一覧」

## 整理の際の方針

- 元のドキュメントに一切なかった情報の追加・要約による省略は行っていません（表現の整形のみ）。
- 元PDFに第11回〜第14回の内容がほぼ丸ごと2箇所に重複していたため、依頼に基づき1つに統合しています。
- 元のpdftotextでの改行崩れ・箇条書き記号（●/○）・ショートカット表のレイアウト崩れを、Markdown形式（見出し・箇条書き・表）に修正しています。
