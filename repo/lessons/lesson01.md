# 第1回 プリミティブモデリング

ショートカットキーをいっぱい覚える。

- X か Del : 選択物を削除
- Shift + A : 追加を表示 (例: 追加 → メッシュ → モンキー)
  - なぜモンキーを使うか：向きがわかりやすいため
- G : 移動 (Grab)
- R : 回転 (Rotate)
- S : 拡大縮小 (Scale)
  - 頭文字で覚えると覚えやすいです

### オブジェクトの基本操作

- オブジェクト選択後、Gキーを押してオブジェクトが動くことを確認する。
  - 右クリックでキャンセル、左クリックで確定
- Rキーを押してオブジェクトが回転することを確認する。
- Sキーを押して拡大縮小することを確認する。
  - マウスカーソルがオブジェクトの中心に近い場合、拡大縮小が極端になるため、ある程度距離を開けて操作する。

### 位置・回転・スケールの初期化

※ Alt は初期化の意味合いを持つショートカットに使われることが多い。

- Alt + G : 位置を0に
- Alt + R : 回転を0に
- Alt + S : スケール値を1に

### 詳細な操作と確認

- N : サイドバーを表示。アイテムでそのオブジェクトのパラメータを確認できる。
- 2m上に移動する:
  - G を押して X or Y or Z を押して軸移動できることを確認する。
  - Z を押して上下移動することを確認する。
  - 2 を入力して左クリックで確定。
  - アイテムで位置Zが2mになっていることを確認。
- 軸固定で回転:
  - R を押す。X or Y or Z を押して軸固定で回転することを確認。
  - Y を押して 90 と入力、その後左クリックで確定。
- Alt + R, Alt + G で一旦初期位置に戻す。
- サイズ変更:
  - S を押して .5 と入力でサイズが1/2になることを確認。

### 実践：魔法使いの工房づくり

15回かけて「魔法使いの工房」をイメージしてモデリングしていく。最終的にはそれぞれの
工房のシーンが出来上がるように。

### まずはフラスコを作成していく

物の形を捉えていく。

- Shift + A → メッシュ → UV球体
- Shift + A → メッシュ → 円柱
  - 重なって見えなくなる。
  - G だけで動かすと位置がずれるため、G → Z で高さだけ変更。
  - S で太さをどのぐらいにするか考えながら小さくする。
  - 高さだけ変更したいので、S → Z で高さ方向だけ拡大縮小してフラスコっぽくしていく。
  - めり込んでいると各オブジェクトが透明になった際に見た目がおかしくなるので、なるべく重ならない位置にする。
- 実際の丸底フラスコの画像を見ながら、先端が太く丸くなっていることを指摘。
- Shift + A → メッシュ からどれがいいか：トーラスが近いのでそれを生成。
  - G → Z で円柱の上まで移動。

> **Q:** こういうのって形の理由も気になったら調べた方がモデリングにはいいですか？
> **A:** 重要。意味、構造を理解してモデリングすることで良い形になるため。ついでにいろんなことを知れて楽しい。

### シェード（見た目）の設定

- UV球：選択 → 右クリック → スムーズシェード
  - 見た目は滑らかになるけどポリゴンはそのまま。
- 円柱：選択 → 右クリック → スムーズシェード
  - 影が違和感 (斜めに影が入る)。
- 円柱：選択 → 右クリック → 自動スムーズシェード
  - 影が縦に入りいい感じに。角ばったところがある場合、自動スムーズシェードのほうが見た目がいい。
- トーラス：選択 → 右クリック → 自動スムーズシェード
  - 違和感を感じる見た目に。
  - 右のスパナマークのモディファイアーで角度を指定。デフォルト30度だが、それより大きい角度があるので一部が板状になる。
- トーラス：選択 → 右クリック → スムーズシェード
  - いい感じになることを確認。
> **Q:** 画面の中に描いていく機能の解説は？
> **A:** D を押しながら左クリックで描ける。D を押しながら右クリックで消せる。一時的なメモ・説明などに利用できる（実際のモデルには影響しない）。

### マテリアルの設定

- UV球を選択してマテリアルを作成。一意な名前を英語でつける。
- 円柱、トーラスにも同じマテリアルを設定。（新規せずにアイコンをクリックして選ぶ）
- 赤い液体が入っているふうにする：
  - UV球を選択し、マテリアル名横の×アイコンをクリックしてリンクを解除。
  - 新しくマテリアルを作成して、ベースカラーを赤色に。
- 編集画面の右上で「ビューポートシェーディング：マテリアルプレビュー」に変更。
  - Z を押すとショートカットが出るので選択することもできる。

> **Q:** ライトが消えているのですがどうすればいいでしょうか？
> **A:** Shift + A からライトを追加。

### オブジェクトの統合

- 3つのオブジェクトをまとめる：
  - 統合先となる代表オブジェクト（今回はSphere）を選択する。
  - ドラッグの範囲選択で3つのオブジェクトを選択する。
  - 右クリック → 統合
- 3つのオブジェクトが1つになり、全てにスムーズシェードがかかるため円柱部分の表示がおかしくなる。
  - 自動スムーズシェードを設定して、トーラスがいい感じになるまで自動スムーズシェードの角度を大きくする。
- 次に作成するモデルのため、一旦丸底フラスコをX－５の位置に変更：G → X → -5
課題１：円錐底、四角底のフラスコモデルを作成

> **Q:** 統合してしまったものをいったん解除する方法はありますか？
> **A:** オブジェクトを選択後、編集モードへ。右クリック → 分離 → 「構造的に分離したパーツで」を選択。

### フラスコの配置とテーブル作成

- 地面の高さに作成したフラスコを移動していく。画面右上ギズモの-Yをクリック（テンキーがある場合 1）。
- すべて選択して G → Z → 1。各フラスコの底部が赤線に重なる感じになっているか確認。
- テーブルを作成していく：
  - 真ん中でテーブルを作成していくため、フラスコをすべて選択して G → X→ -5
  - 立方体作成。Z をテーブル天板の厚みになるように縮小、Y を長方形テーブルになるように縮小。
  - G でテーブル上部が赤線に重なるように調整。（フロントビューで）
  - トランスフォームピボットポイントを3Dカーソルに変更して縮小し、中点に戻しておく。（画面中央上部にある小さなアイコン）
- 机の足を作成していく：
  - 立方体を作成して、まず縮小で柱の太さを決める。
  - その後拡大縮小でY方向を拡大。位置をいずれかの角に移動。
  - 真上の画面に移動（右上ギズモのZを押して）。
  - Z からワイヤーフレーム表示に切り替える。
  - Shift + D (選択オブジェクトの複製) で複製したオブジェクトをY固定で対面に移動。
  - 2つのオブジェクトを選択して Shift + D で複製し、X固定で対面に移動。

### 提出

- 全体が映るようにして Win + Shift + S でスクリーンショットを取って、クラスルームの課題から提出。
