# 第3回 ミラー、配列、PBRマテリアル

## 1. 授業の概要・目標
今回は編集モードの復習としてろうそく立て（燭台）を制作しながら、以下の機能を学びま
す。

- ミラー（左右対称コピー）
- 配列（複製を並べる）
- 原点（オブジェクト中心）
- マテリアル基礎（PBRの考え方）

## 2. 復習制作：ろうそく
円柱からろうそくを制作します。

### 手順例

1. 円柱 を追加
2. 上面を選択し、E (押し出し) → S (縮小) で芯の部分を作成
## 3. Ctrl + R でループカットを追加し、中央をへこませる

### Tip

### 状態の表現

- 使用済み: 上部が熱で溶けてへこんでいる
- 未使用: 先端が芯に向かって盛り上がっている

3. ミラー (Mirror)
左右対称な形状を自動で生成する機能です。

- 場所: モディファイアプロパティ ＞ 生成 ＞ ミラー
- 効果: 片側だけ作成すれば、反対側も同期して生成されます。
- ミラーオブジェクト: 中央にあるオブジェクトを指定することで、その位置を基準に左右対称になります（スポイトで選択）。

## 4. 原点 (Origin) の重要性
オブジェクトの「中心点（原点）」の扱いは非常に重要です。

- 用途:
  - 回転の中心
  - ミラーの基準点
  - 配列の基準点
- 修正方法: オブジェクトメニュー ＞ 原点を設定 ＞ 原点を3Dカーソルへ移動 など。３Dカーソルが原点に居ない場合はShift+S＞カーソル＞ワールド原点してから。

## 5. 配列 (Array)
同じオブジェクトを一定間隔で複製する機能です。

- 場所: モディファイアーを追加 ＞ 生成 ＞ 配列
- 基本設定:
  - 数: 複製の個数
  - オフセットメソッド: 相対は自身を何個分間隔、オフセットはm単位、終端はここまでに何個
  - XYZの値で方向と距離を指定する。（回転やスケールも可能）

## 6. 円形配列
シェイプをラインから円に変更することで、円形に配置できます。

- 使用例: 燭台の4方向アームなど。
- 設定: 数 と 半径 を調整することで、4本足の燭台などが簡単に作れます。
- 原点を中心に作られるので、原点位置の修正が必要な場合もあります。

## 7. スケール適用（超重要）
Important

オブジェクトモードでの拡大縮小は「仮の倍率」として扱われます。これを忘れると以下の
不具合が発生します。

- 配列の間隔が数値通りにならない
- Ctrl+右クリックの押し出しが思い通りの形にならない
- ベベルの幅が歪む

修正方法:オブジェクトモードで Ctrl + A ＞ スケール
これにより、現在の見た目のサイズが「正式なサイズ = 1.0」として確定されます。

## 8. Ctrl + 右クリック押し出し
編集モードで面を選択中、Ctrl + 右クリック を押した地点へ向かって連続的に押し出しが
可能です。

- 用途: 曲がった柱、S字アーム、パイプ形状などの有機的な押し出し。
- 注意: ドラッグではなく「クリック」で行います。

## 9. シャープをマーク
なだらかな面（スムーズシェード）の中に、鋭い角を残したい場合に使用します。

- 操作: 辺を選択 ＞ 右クリック ＞ シャープをマーク
- 表示: 指定された辺は青い線で表示されます。

## 10. マテリアルの塗り分け
1つのオブジェクトに対して複数の色（マテリアル）を適用できます。

### 手順

1.   マテリアルプロパティで + をクリックし、スロットを追加
2.   新規 作成、または既存のマテリアルを選択
3.   編集モード で割り当てたい面を選択
4.   割り当て (Assign) ボタンをクリック

## 11. PBR (Physically Based Rendering) とは
現実の物理法則（光の反射や吸収）に基づいて質感を作る方式です。現在のCG業界における
標準的な手法です。「現実の素材をよく観察して設定する」ことが基本となります。

## 12. マテリアルの主要パラメータ
- ベースカラー: 素材そのものの色。
- メタリック (Metallic): 金属かどうか。基本的には 0 (非金属) か 1 (金属) のいずれかを使用します。
- 粗さ (Roughness): 表面のざらつき。0～1の間で設定します。
  - 0: 鏡のようにツヤツヤ（正反射）
  - 1: 光が拡散してマットな質感

## 13. 観察が大事
数値を適当に決めるのではなく、実物をよく観察しましょう。
- 本物の金属はどの程度反射するか？
- ロウの表面にはどの程度のツヤがあるか？
- 真鍮は磨かれているか、それともくすんでいるか？
