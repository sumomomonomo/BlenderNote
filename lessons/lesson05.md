## 1. 今回のテーマ 「厚みのあるモデル」
平面だけのハリボテ↓厚みのある立体特に： ソリッド化（Solidify） が重要

## 2. 復習      丸椅子制作

## 3. 円形に配列する（Radial Array）
方法

- Array Modifier → シェイプ（Shape） をライン（LIne）ではなく円（Circle）に設定。
- 半径で足位置調整。

## 4. スケール適用の再確認（超重要）Important

問題： 見た目は小さいのに Array 半径が6mと巨大。ベベルも歪む原因： オブジェクトモード S の未適用解決法： Ctrl + A → スケールすると： Scale = 1.0 つまり現在のサイズが基準となり、モディファイアの効果が正常化
する

## 5. 編集モードスケールの利点
編集モードで S した場合、オブジェクトの Scale 値は変化しない。つまり：

- Ctrl + A の工程が不要になる。
- 先生： 編集モードでのスケールは、手間が減ってスケールの適用忘れも防げる。2
1.~22.を理解して使い分けよう。

## 6. 足の45度回転
編集モードで R → Z → 45 足を45度回転。理由：

- 4本脚の側面が互いに向き合うことで、補強パーツが配置しやすくなる。

オブジェクトモードで R → Z → 45 足を45度回転。
理由：

- 椅子の向きが◇から□になり、補強パーツの回転が不要になる。

## 7. 面だけ移動
底面だけを移動：G → Y→ Y （ローカルY方向へ移動）

- 足を外側へ広げる
- 安定感UP これは実際の家具構造っぽくなる
## 8. 配列の回転同期
Array 配列では： 全オブジェクト同方向を向く例：

- モンキー の顎が全方向で同じ向きに伸びるこれ理解すると：
- 7.のような操作が思い付き、配列を使った効率的なモデリングが出来るようになる。
## 9. 自動スムーズシェード
右クリック → 自動スムーズシェード

- 硬い角だけシャープ化。
- モディファイアーの順序が最後に固定されている。画鋲アイコンをクリックで解除。

## 10. スムーズシェードとの違い
ベベル後は 普通のSmooth Shadeの方が綺麗な場合あり。

- 理由： 角そのものが曲面化済みだから。

## 11. 重み付き法線（Weighted Normal）
効果

- 平面の余計なグラデーション除去。
- 円柱状のグラデーションの傾き除去。
- 工業製品のような人工物に効果的。
- マウスホイール セグメント増減。

## 12. ベベル復習
モディファイア版

- 角度しきい値による全体角丸め。編集モード版 Ctrl + B
- 選択部分だけベベル。
## 13. 親子付け（Parent）Important

超重要！！方法 Ctrl + P → Object仕組み

- 親を動かす → 子も動く
- 子を動かす → 親は動かない使用例 椅子： 座面 （親）足（子） にすると、座面の移動で椅子全体を動かせる。関節構造：上腕（親）前腕（子）にすると、回転で関節の動きが作れる

## 14. 親子解除
Alt + P 「トランスフォーム維持」

- 位置を保ったまま解除。

## 15. マテリアル一括コピーTip

### 超便利！！方法

2. 最後に素材元選択
3. マテリアルタブ ＞ ▼メニュー ＞ 「マテリアルを選択物にコピー」

## 16. ソリッド化（Solidify）
今回最大のテーマ！！何をする？

- 平面に厚みを付ける。追加場所
- モディファイア ＞ 生成 ＞ ソリッド化

## 17. ソリッド化の利点
厚みを後から変更可能つまり：

- コップ 缶 鎧 葉っぱ 布 全部調整可能！！
- モデリング中に、厚みの頂点を操作する手間が消える

## 18. Offset
厚み方向設定。

- -1 内側
- 1 外側
- 0 両側

## 19. 均一（Even Thickness）
ONにすると：

- 厚み均一化 斜め潰れ防止

## 26. 円錐側面をループカットできない理由
三角形メッシュだから。

- Ctrl + R 四角面専用。解決法
- 辺選択 ＞ 右クリック ＞ 細分化 これで疑似ループカット。これで三角フラスコが作れる。

## 27. GGスライド
G → G 辺上をスライド移動。

- 形を変えずに頂点や辺の位置を変えられる。
- ループカット後の調整に便利。
## 28. 液体制作（超重要）Important

### 手順

1.   Shift + D 複製、右クリック決定で重ねる
2.   Solidify を適用
3.   上部の厚み部分を選択、面を削除して、表と裏を分離。
4.   L 接続面一括選択。
5.   外側削除 内側だけ残す。
6.   液体の量を考え、不要となる上部を削除
7.   削除した断面の辺をループ選択して、F で液面を貼る。
8.   全ての面を選択し、Alt + N で面の向きを外側へ揃える。

## 29. 面の向き（Normal）
CGでは超重要。

- Alt + N 面方向修正。
- Shift + N 自動外向き。
