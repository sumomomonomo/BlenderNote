# 第2回 編集モード

## 1. 授業の概要・目標

第2回では、前回学んだプリミティブモデリングの復習を行った後、Blenderの重要機能である
編集モードを学習した。
今回のテーマは以下の2段階。

- プリミティブで望遠鏡を作る復習課題
- 編集モードを使って、1つのオブジェクトから形状を作る練習

編集モードを使うことで、複数オブジェクトを組み合わせずに、1つの立方体や円柱から複雑な
形を作れるようになる。

## 2. 復習課題：望遠鏡の制作

### 内容

前回学んだプリミティブモデリングの復習として、望遠鏡を制作。

### 使用する主なプリミティブ

- 円柱（筒部分）
- トーラス（装飾リング）
- 必要に応じて複製

### ポイント

- 細かい装飾は後回しでよい
- 大まかなシルエットを優先する
- 徐々に細くなる形を意識する

### ショートカット復習

- Shift + D：複製
- R → 軸 → 90：90度回転
- G：移動
- S：拡大縮小

## 3. 編集モードとは

### オブジェクトモード

オブジェクト単位で移動・回転・拡大縮小するモード。

### 編集モード

オブジェクトそのものの形状を変形するモード。

### 切り替え

- Tabキーで切替
- かなり頻繁に使うため必須操作。

## 4. 点・辺・面の選択

編集モードでは3種類の選択モードを使う。

### ショートカット

- 1：頂点（点）
- 2：辺
- 3：面

### 特徴

- 点選択: 1点だけでは回転・スケールの意味が薄い。主に位置調整。
- 辺選択: 辺単位で回転・拡大可能。
- 面選択: 最もよく使う。面単位で移動・押し出し・変形が可能。

## 5. 面スケールで形を作る

面選択状態でSキーを使うことで、以下が可能。
- 上に向かって細くする
- フタ形状を作る
- 富士山型にする

### 例：

- 円柱の下面を縮小 → コルク栓
- 円柱の上面を縮小 → 円錐状パーツ

## 6. 押し出し（Extrude）

- ショートカット: E
- 面から新しい面を伸ばす機能。超重要。

### 用途

- 柄を伸ばす
- 筒を伸ばす
- T字型パーツ作成
- 新しい構造物を生やす

### 補足

点や辺でも押し出し可能だが初心者には扱いが難しい。

## 7. ループカット

- ショートカット: Ctrl + R
- 形状に切れ目（分割線）を入れる機能。使用頻度が非常に高い。

### 特徴

- マウスカーソル位置の辺を分割するようにループカットされる。
- クリック後スライド位置調整可能
- 右クリックで中央50%固定

### 用途

- 中間地点から押し出したい時
- 曲線を作るため分割を増やす時
- ディテール追加

## 8. 押し出し + スケール（ES）

### 手順

1. Eで押し出し
2. そのままSで拡大縮小

### 効果

- 途中から細くする
- 途中から太くする
- 望遠鏡の段差表現
- かなり強力な組み合わせ。

## 9. インセット

- ショートカット: I
- 面を内側に差し込む機能。

### 用途

- へこみ作成
- 宝箱のフチ
- パネル表現
- ディテール追加

### 補足

複数面まとめて使える。
Iを押すたびに全体、個々が切り替わる

## 10. 表示モードと見やすさ調整

### ソリッド表示
- モデリング時に形状確認しやすい。
- Z → Solid

### キャビティ表示

- 凹凸を見やすくする。
- ソリッド表示中に設定：
  - キャビティ ON
  - Type：両方
- これで辺やへこみが見やすくなる。

## 11. 裏側選択の方法

### 方法1：ワイヤーフレーム

- Z → Wireframe
- 裏側まで囲んで選択可能。

### 方法2：透過表示

- Alt + Z
- マテリアル表示のまま裏側も選択できる。

## 12. ループ選択

- ショートカット: Alt + クリック
- 辺を一周まとめて選択。

### ループの追加選択

- Shift + Alt + クリック
- 本のページ制作時に使用。

## 13. 実践制作：開いた本（魔導書）

立方体から制作。

左右対称の移動には、両方選択してスケールを使う。S → X
流れ

1. 平たくスケールして本の形にする
2. ループカット3本
3. 中央の辺を下げて開いた形にする
4. 左右のループを調整
5. 追加ループカットで曲線を滑らかにする

### 学び

曲面は一気に作らず、

1. まず大きい変化
2. 必要な所だけ分割追加で作る。

## 14. モデリングの考え方（重要）

曲面を見る時は、

- 一番出っ張る場所
- 一番へこむ場所
- 中間地点を観察して、そこに分割線を入れて形を作る。つまり「物を見る力」が大事。

## 15. 今回の重要ショートカットまとめ

- Tab：編集モード切替
- 1 / 2 / 3：点・辺・面選択
- E：押し出し
- Ctrl + R：ループカット
- I：インセット
- Alt + クリック：ループ選択
- Shift + Alt + クリック：追加ループ選択
- Alt + Z：透過表示
- Z：表示切替
