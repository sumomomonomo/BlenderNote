# 第12回 Append・PureRef・スカルプト実践

## 1. 今回のテーマ
- 前回作成したオブジェクトを別シーンへ読み込むアペンド（Append）と、Subdivision Surfaceで作成したベースメッシュを利用したスカルプト制作を学んだ
- PureRefを利用した資料管理と、「資料を見ること」の重要性についても学んだ

## 2. 親子付け
複数オブジェクトを一括で動かしたい場合は親子付けを行う。
手順
- 親にするオブジェクトを選択
- 他のオブジェクトを追加選択
- Ctrl + P → トランスフォーム維持
これにより親だけ動かせば全体が一緒に移動する。
代表となるオブジェクトには、Fan・Table・Windowなど分かりやすい名前を付け
る。

## 3. アペンド（Append）
他のBlendファイルからオブジェクトだけ読み込める機能。
- File
- Append
- Object
- フォルダを開き、必要なオブジェクトだけ選択して読み込む
Blendファイル内部にはオブジェクト（Object）・メッシュ（Mesh）・マテリアル
（Material）・画像（Image）・コレクション（Collection）・カメラ（Camera）な
どが整理されて保存されており、必要なデータだけ読み込める。

## 4. Appendの利点とシーン分割
Appendを使うことで、部屋・家具・小物などを別々に制作して最後にまとめられ
る。チーム制作でも非常に便利。
Append後は親オブジェクトだけ選択すれば全体を移動できる。
先生の推奨制作方法は、制作専用シーンと完成シーンを分けること。完成シーンで
は新規モデリングをせず、Appendで集める。

難しければ、Ctrl+C、Ctrl+Vでシーンをまたいだコピー貼り付けもできる。

## 5. 今回の課題①
前回制作した使い魔を、Subdivision Surfaceを利用したベースメッシュ方式でもう
一度制作する（リベンジ制作）。

## 6. PureRef
資料画像管理ソフト。
特徴
- ドラッグ＆ドロップだけで画像追加
- 複数画像管理
- 軽い
- 常に最前面に表示できる
- モデリング向き
公式サイトのCustom Amountを0にすると無料でダウンロード可能。
## 7. PureRef基本操作

操作               キー / 動作

### 画像追加     ドラッグ＆ドロップ

### 文字入力     Ctrl + N

### 画像移動     右ドラッグ

### 画面移動     中ドラッグ

### ズーム      マウスホイール

常に最前面表   Ctrl + Shift + A または画鋲ア
示        イコン

## 8. 資料を見る重要性
モデリングでは作る時間より資料を見る時間の方が重要である。
先生は、作品の完成度は技術よりも観察時間の差が大きいと説明した。
美術教育では「見る：9、描く：1」くらいの割合で観察する。思い込みではなく実
物を見る習慣が重要。

## 9. ベースメッシュ制作
まず胴体・足・頭など大まかな形をSubdivisionで作る。スカルプトでは細部だけ修
正する。
先生はトカゲを例に、背中・お腹・足などをプリミティブモデリングだけで近づけ
た。
ループカット（Loop Cut）を利用すると、背中を平らにする・お腹を膨らませるな
ど、スカルプト前に形を整えられる。
脚や腕は別オブジェクトとして制作してから最後に統合する方法も有効。
ベースメッシュがほぼ立方体なので、上腕を複製して下腕としたり、指としたりで
きる。オブジェクトモードで回転した後でも、S → X → X（Xを2回押してローカル
軸方向へスケール）で幅を調整することで、長さ調整が可能

## 10. スカルプト準備
左右対称モデルは半分だけ作り、ミラー（Mirror）モディファイアを利用する。Mir
ror使用時は二分割（Bisect）を有効にすると、中央で重複メッシュが発生するのを
防げる。
Subdivisionの適用は右クリック→変換→メッシュで行う。複数オブジェクトへ一括
適用できる。
スカルプトモードへ移行する手順
- 右クリック→変換→メッシュ
- Ctrl + Jでオブジェクトを統合
- スカルプトモードへ切り替え
- Rでリメッシュサイズを調整
- Ctrl + Rでリメッシュ
目は眼球を球体のまま利用し、まぶただけスカルプトする方が綺麗。歯や羽なども
別オブジェクト推奨。

## 11. リメッシュ時の穴
穴が空いた場合
- 編集モード
- 穴の周囲を選択
- Fで面を貼る
- リメッシュをやり直す

## 12. ブラシの使い方
先生おすすめのブラシ
- Inflate
- Clay Strips
- Grab
- Smooth
強さは0.2〜0.4程度の弱めがおすすめ. 少しずつ積み重ねる方が綺麗になる。
丸くしたい場合はInflateを使い、途中でリメッシュしながら形を整える。ブラシは
近距離より少し離れて十分に覆う大きさで使う方が綺麗。
## 13. スカルプト上達法
Tip

先生は「上手になる近道はない」と説明。たくさん遊び、ブラシに慣れることが重
要。

先生自身のBlender使用時間は約8896時間。技術は才能より積み重ねた時間の影響が
大きいと説明した。
授業だけでは十分な制作時間は確保できないため、上達には自主制作を続けること
が重要。

## 14. 今回の課題②
Subdivision Surfaceを利用してベースメッシュを作成し、リメッシュ後に使い魔を
スカルプトする。同じモチーフでも別のモチーフでも可。

## 15. 今回の重要ポイント
- アペンド（File→Append→Object）で他のBlendファイルからオブジェクトを読み込める
- Ctrl + Pで親子付けし、一括移動できる
- PureRefで資料画像を効率的に管理する
- モデリングでは「資料を見る時間」が非常に重要
- ベースメッシュを作ることでスカルプト作業を大幅に効率化できる
- 右クリック→変換→メッシュでSubdivisionを一括適用
- Ctrl + Jでオブジェクトを統合し、R→Ctrl + Rでリメッシュする
- Mirror使用時はBisectを有効にして中央の重複メッシュを防ぐ
- 目・歯・羽などは別オブジェクトのまま作ると仕上がりが良い
- ブラシは弱めの設定で少しずつ形を作る方が自然な造形になる
- 上達には観察・反復・自主制作が重要であり、継続的な制作時間が技術向上につながる
